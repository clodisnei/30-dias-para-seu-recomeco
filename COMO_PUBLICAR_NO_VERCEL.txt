PUBLICAÇÃO NO GITHUB E VERCEL

1. Extraia este ZIP.
2. Adicione a capa e os áudios seguindo ADICIONAR_CAPA_E_AUDIOS.txt. Isso também pode ser feito depois.
3. Envie TODOS os arquivos e pastas para a raiz do repositório no GitHub.
4. Verifique se index.html aparece diretamente na raiz.
5. No Vercel:
   Framework Preset: Other
   Root Directory: ./
   Build Command: vazio
   Output Directory: vazio
   Install Command: vazio
6. Faça Deploy ou Redeploy.

IMPORTANTE
Não envie apenas o ZIP ao GitHub. Extraia-o primeiro.
As pastas audio e capa contêm arquivos LEIA-ME.txt para que sejam mantidas pelo GitHub mesmo antes de você adicionar os MP3 e o JPG.
